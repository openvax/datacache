    Public API reference¶

    This reference covers every name exported in datacache.__all__ and every public Cache method. Import these names from datacache. Signatures and parameter descriptions are generated directly from the source docstrings.

    Start with the quickstart for a first download, or run through the self-contained API examples. The download guide, archive guide, data guide, progress guide, and shared-cache guide explain the longer workflows and compatibility guarantees.

    Downloading¶

    fetch_file ¶

    fetch_file(download_url, filename=None, decompress=False, subdir=None, force=False, timeout=None, use_wget_if_available=None, chunk_size=DEFAULT_CHUNK_SIZE, progress_callback=None, *, destination=None, cache_root=None, expected_sha256=None, expected_size=None, max_bytes=None, max_retries=DEFAULT_MAX_RETRIES, retry_backoff=DEFAULT_RETRY_BACKOFF, retry_max_delay=DEFAULT_RETRY_MAX_DELAY, show_progress=False, record_provenance=False, allow_empty=False, resume=False, raw=False, http_representation='decoded', expire_after=None, return_stale_on_error=False, validator=None, offline=None)

    Download a remote file and store it locally in a cache directory. Don't download it again if it's already present (unless force is True, or the cached copy is older than expire_after).

    Parameters:

    Name Type Description Default
    download_url str

    Remote URL of file to download.

    		 required
    filename str

    Local filename, used as cache key. If omitted, then determine the local filename from the URL.

    		 None
    decompress bool

    With an inferred filename, archives are retained by default, including for URLs with query strings or fragments. Set True to decompress them under a distinct cache key. An explicit filename or destination lacking the source's .zip/.gz suffix still implies decompression for compatibility.

    		 False
    raw bool

    Disable archive decompression and HTML-to-CSV conversion regardless of the output name. Incompatible with decompress=True. Defaults to False, preserving legacy output-name inference. Integrity expectations then describe the payload selected by http_representation.

    		 False
    http_representation decoded or encoded

    "decoded" (default) keeps Requests' HTTP Content-Encoding decoding. "encoded" requires raw=True and preserves those encoded body bytes, while still removing HTTP chunk framing. It requests identity encoding to avoid negotiated compression; sources that supply Content-Encoding anyway are preserved. Hashes, sizes, byte limits, progress, provenance and resume offsets all refer to the selected bytes. File/FTP sources are copied unchanged and must already contain the desired representation. Cache keys do not change: use distinct paths or trusted expectations. A recorded representation mismatch rejects reuse, including stale fallback.

    		 'decoded'
    subdir str

    Application name selecting a platform cache directory, "datacache" by default. It is not nested inside the default cache. Ignored when cache_root is supplied.

    		 None
    force bool

    By default, a remote file is not downloaded if it's already present. However, with this argument set to True, it will be overwritten.

    		 False
    timeout float or (float, float)

    Per-attempt connect/read timeout in seconds. The default None waits indefinitely. HTTP(S) also accepts a Requests (connect, read) tuple.

    		 None
    use_wget_if_available bool

    Deprecated and ignored. datacache now always uses its streaming Python downloader (which handles http(s) and ftp); the legacy wget path was removed. Passing this argument emits a DeprecationWarning.

    		 None
    chunk_size int

    Number of bytes to stream from the server to disk at a time. Defaults to 1 MB.

    		 DEFAULT_CHUNK_SIZE
    progress_callback callable

    If provided, called as progress_callback(bytes_downloaded, total_bytes) after each chunk is written, where total_bytes is the server-reported size or None if unknown. Lets callers render a progress display in their application's own UI instead of the built-in bar.

    		 None
    show_progress bool

    Show tqdm download, decompression, and hash-verification progress. tqdm is installed with datacache. Defaults to False; cache hits are quiet. Can be combined with progress_callback. Each retry starts a fresh bar.

    		 False
    destination str or PathLike

    Exact output path, including filename, instead of the default cache. Mutually exclusive with filename, subdir, and cache_root. Parent directories are created only when downloading. With decompress=True, the destination name is kept exactly as supplied while archive contents are installed.

    		 None
    cache_root str or PathLike

    Directory containing cached files, overriding the location selected by subdir. Cannot be combined with destination.

    		 None
    expected_sha256 str

    Trusted SHA-256 hex digest of the installed bytes, after any requested decompression or HTML conversion. In raw mode these are the selected HTTP representation, or the unchanged bytes of a file/FTP source. Checked both on cache reuse and before publishing a replacement.

    		 None
    expected_size int

    Expected non-negative byte count of the same installed bytes.

    		 None
    max_bytes int

    The most bytes any file this fetch writes may hold, checked before every write. It bounds the selected HTTP body representation (whether or not Content-Length is sent), and the installed file after decompress=True, so allow for the compressed download too; together they never need more than twice max_bytes. A larger transfer raises FileValidationError without retrying: an existing file stays and temporary files are removed. Cache hits write nothing and are unaffected. expected_size must not be larger, and HTML-to-CSV conversion can't be bounded; options that can't work together raise ValueError, even on a cache hit. Default None: no limit.

    		 None
    max_retries int

    Additional attempts after transient HTTP/transport failures, default 2. Set 0 to disable retries. File and FTP transfers are not retried.

    		 DEFAULT_MAX_RETRIES
    retry_backoff float

    Initial retry delay in seconds, default 1. Doubles after each retry, capped by retry_max_delay. Progress counts restart for each attempt.

    		 DEFAULT_RETRY_BACKOFF
    retry_max_delay float

    Maximum delay between attempts, default 30 seconds. Retry-After is honored when within this limit; longer server waits stop retries. timeout still applies per attempt, not as a total download deadline.

    		 DEFAULT_RETRY_MAX_DELAY
    resume bool or auto

    Keep private partials and resume raw HTTP(S) transfers, default False. "auto" resumes whenever it can and otherwise downloads normally: when the platform, URL, size or options don't allow it, and when the server turns out not to support it (the partial is then discarded and the file downloaded in full). resume=True instead raises in those cases. Requires expected_size and a POSIX local filesystem. If expected_sha256 is omitted, the server must supply a strong ETag on every accepted response; it is sent as If-Range when resuming. ETags prevent mixing representations, but do not verify a trusted checksum. Cache hits with size alone check only their byte count. Does not support decompression or HTML conversion; raw=True permits arbitrary output names. Retries report cumulative bytes, resetting only when the server requires a fresh transfer. discard_partial(destination) explicitly drops partials. Interrupted downloads retain at most expected_size partial bytes. Encoded mode resumes encoded bytes and checks Content-Encoding across ranges. Decoded mode requires identity Content-Encoding for resume; "auto" falls back to a full decoded transfer otherwise.

    		 False
    record_provenance bool

    After publishing a download, also write a hidden "..datacache.json" record of http_representation and the source URL (without user name, password, query, or fragment; the path is kept as is), fetch time, size, and the SHA-256 when expected_sha256 verified it, which inspect_file reports offline. The record has the file's permissions. Off by default: a caller that downloads to a temporary name and then moves the file would leave the record behind. Cache hits never write one, and any new download removes a previous record first.

    		 False
    allow_empty bool

    Accept an empty file, default False. A complete but empty response, such as a withdrawn upstream record, is otherwise never published: HTTP retries it as transient, then FileValidationError is raised. An empty cached file is likewise invalid. expected_size=0 also allows it.

    		 False
    expire_after float or timedelta

    How long a cached file stays fresh, in seconds or as a timedelta, like requests-cache's option of the same name. An older cached file is downloaded again, as is one that no longer validates; 0 refreshes every time. Its age comes from the provenance record's fetch time when one describes the file (see record_provenance), otherwise from its modification time; a future time counts as new. Default None reuses a valid file however old and raises for an invalid one.

    		 None
    return_stale_on_error bool

    When a refresh (force=True or an expired expire_after) fails with an exception and a valid cached file exists, log a warning and return the cached path instead, as HTTP's stale-if-error directive allows. Without a valid cached file the error propagates, as does an exception from progress_callback, which cancels the fetch. Default False.

    		 False
    validator callable

    validator(path) checks content that a successful transfer can still get wrong, such as an HTTP 200 error page. It rejects the file by raising (normally ValueError) or returning False. It runs on the installed bytes before publication, so a rejected download never replaces the cached file, and on cache hits. Rejection raises FileValidationError, chained to any exception. Not supported with resume=True.

    		 None
    offline bool or None

    Override DATACACHE_OFFLINE / OPENVAX_OFFLINE. When offline, cache hits and file:// URLs still succeed, while remote transfers raise OfflineError before modifying disk.

    		 None

    Returns:

    Type Description
    str

    Local path string (not necessarily absolute when given a relative destination or cache_root).

    Raises:

    Type Description
    ValueError

    For conflicting paths or invalid expectations, chunk size, byte limit, retry options, callback, or progress flag. Empty ZIP archives also raise ValueError.
    FileValidationError

    For non-regular files, empty responses (unless allow_empty=True), or size, digest, representation, or validator mismatches.
    OfflineError

    When offline mode forbids a remote transfer.
    InsufficientSpaceError

    When the destination filesystem runs out of disk space (ENOSPC) during directory creation, download, decompression, or publication. Staging files are removed (or, when resume is enabled, only the private resumable partial file is retained) and the destination file is left untouched.
    OSError

    For other filesystem access or publication failures (such as PermissionError).
    RequestException

    For HTTP failures, preserved after retry exhaustion.
    URLError

    For URL-handler failures on file or FTP sources.
    ImportError

    If HTML-to-CSV conversion is requested without datacache[html] (lxml).
    Notes

    A corrupt cache hit raises FileValidationError; use force=True for an explicit repair. Failed downloads (including InsufficientSpaceError on ENOSPC) leave any existing destination unchanged and remove staging files (when resume is enabled, only the private resumable partial is kept and never exposed at the final destination). Atomic replacement requires a local filesystem supporting os.replace. Staging files remain private until publication; new files use normal creation permissions (0666 filtered by umask) and replacements preserve existing read/write/execute bits.

    ZIP downloads install the member stored at the output name, otherwise a member with that name ignoring letter case in any folder (nearest the archive root, then exact-case match, then largest), or else the largest non-directory member. HTML-to-CSV conversion is enabled by an explicit .csv output for an HTML source and requires datacache[html].

    fetch_bytes ¶

    fetch_bytes(download_url, *, timeout=None, max_retries=DEFAULT_MAX_RETRIES, retry_backoff=DEFAULT_RETRY_BACKOFF, retry_max_delay=DEFAULT_RETRY_MAX_DELAY, allow_empty=False, max_bytes=None, offline=None)

    Return a remote resource's bytes in memory, transferred and retried exactly as fetch_file downloads are. Nothing is written to disk.

    Meant for small resources such as directory listings and metadata: the whole body is held in memory. It also works where a cache is read-only.

    Parameters:

    Name Type Description Default
    download_url str

    HTTP, HTTPS, FTP, or file:// URL.

    		 required
    timeout optional

    As for fetch_file: a per-attempt timeout (None waits indefinitely), and retries of connection errors, 408/429/5xx responses and empty bodies with capped backoff that honors Retry-After. Only HTTP(S) transfers are retried.

    		 None
    max_retries optional

    As for fetch_file: a per-attempt timeout (None waits indefinitely), and retries of connection errors, 408/429/5xx responses and empty bodies with capped backoff that honors Retry-After. Only HTTP(S) transfers are retried.

    		 None
    retry_backoff optional

    As for fetch_file: a per-attempt timeout (None waits indefinitely), and retries of connection errors, 408/429/5xx responses and empty bodies with capped backoff that honors Retry-After. Only HTTP(S) transfers are retried.

    		 None
    retry_max_delay optional

    As for fetch_file: a per-attempt timeout (None waits indefinitely), and retries of connection errors, 408/429/5xx responses and empty bodies with capped backoff that honors Retry-After. Only HTTP(S) transfers are retried.

    		 None
    allow_empty bool

    Accept an empty body, default False. An empty HTTP response is otherwise retried as transient, then rejected with ValueError.

    		 False
    max_bytes int

    The largest body to accept, after HTTP transfer decoding. It is checked before each chunk is kept, so the returned bytes never grow past it, and the body is read in chunks no larger than the limit. A larger body raises ValueError without retrying. Default None: no limit.

    		 None
    offline bool or None

    Explicitly forbid (True) or allow (False) remote network transfers. Default None honors DATACACHE_OFFLINE and OPENVAX_OFFLINE. Remote URLs raise OfflineError when offline; file:// URLs are always allowed.

    		 None

    Returns:

    Type Description
    bytes

    Downloaded response body.

    Raises:

    Type Description
    ValueError

    For invalid options, an empty body (unless allow_empty=True), or a body larger than max_bytes.
    OfflineError

    When offline mode forbids a remote transfer.
    RequestException

    For HTTP failures, preserved after retry exhaustion.
    URLError

    For file and FTP failures.

    fetch_and_transform ¶

    fetch_and_transform(transformed_filename, transformer, loader, source_filename, source_url, subdir=None, *, force=False, cache_root=None, download_options=None, show_progress=False, decompress=None)

    Download a source and cache a successful single-file transformation.

    transformer(source_path, output_path) must create and close one regular file at the supplied, initially absent path in a private sibling staging directory (matching the final basename and extension). The output is published atomically only after validation; cache hits call loader(final_path) and ignore source options apart from the decompress checks below. Failed transformations preserve any previous transformed file and clean up staging files.

    Parameters:

    Name Type Description Default
    transformed_filename str or PathLike

    Output filename resolved under the cache directory.

    		 required
    transformer callable

    transformer(source_path, output_path) building the transformed file and returning an object (prefer in-memory results over paths nested inside objects).

    		 required
    loader callable

    loader(final_path) loading an existing cached transformed file.

    		 required
    source_filename str

    Download cache key passed as filename to fetch_file.

    		 required
    source_url str

    Source URL passed to fetch_file.

    		 required
    subdir str or None

    Application name selecting the default output and source cache root.

    		 None
    force bool

    Rebuild the transformed output while reusing the cached source. Pass download_options={"force": True} to refresh the source too.

    		 False
    cache_root str or PathLike or None

    Explicit cache directory for both output and source (unless overridden inside download_options).

    		 None
    download_options dict or None

    Extra keyword arguments copied and forwarded to fetch_file (integrity expectations here validate the downloaded source, not the transformed output). Do not duplicate download_url, filename, or subdir.

    		 None
    show_progress bool

    Default show_progress passed to fetch_file; arbitrary transformer work has no automatic bar.

    		 False
    decompress bool or None

    True requests decompressed .gz/.zip source contents; False requests the source as downloaded. May also be given in download_options["decompress"] (conflicting values raise ValueError). Omitting both does not request decompression except when a nonempty subdir is passed (deprecated; emits DeprecationWarning even on cache hits).

    		 None

    Returns:

    Type Description
    object

    The return value of transformer after a build, or of loader on cache reuse. If transformer returns its staged output path directly as a str or Path, it is remapped to the final published path.

    Raises:

    Type Description
    ValueError

    For conflicting decompress settings or invalid fetch_file options.
    RuntimeError

    If transformer does not create its output file.
    FileValidationError

    If the cached or generated output is not a valid regular file.

    build_local_filename ¶

    build_local_filename(download_url=None, filename=None, decompress=False)

    Choose a cache key filename from a URL or an explicit filename.

    At least one of download_url or filename must be nonempty. An explicit filename takes precedence; otherwise the name combines an MD5 digest of the full URL (for naming, not integrity checking) with the URL text. Special characters /, \, ;, :, ?, and = are replaced with underscores, long names are shortened with a digest, and any name exceeding 255 UTF-8 bytes keeps a digest plus as much of its end (including the extension) as fits. This is a cache key, not an exact path.

    With decompress=True, a trailing .gz or .zip suffix is removed; an inferred archive endpoint without a removable suffix gets .decompressed instead so archive and decompressed keys never collide. No filesystem or network access occurs.

    Parameters:

    Name Type Description Default
    download_url str or None

    Source URL used when filename is omitted or to detect archive endpoints when decompressing.

    		 None
    filename str or None

    Explicit cache key name. Takes precedence over download_url.

    		 None
    decompress bool

    If True, select the decompressed cache key. Default is False.

    		 False

    Returns:

    Type Description
    str

    Normalized cache filename (not a directory path).

    Raises:

    Type Description
    ValueError

    If neither download_url nor filename is supplied.

    get_data_dir ¶

    get_data_dir(subdir=None, envkey=None)

    Return the platform cache directory for an application, without creating it.

    subdir is an application name (default "datacache"), not a directory nested under datacache's own cache:

    • Linux / Unix: $XDG_CACHE_HOME/<subdir>, or ~/.cache/<subdir> when XDG_CACHE_HOME is unset, empty, or relative.
    • macOS: ~/Library/Caches/<subdir>, even when XDG_CACHE_HOME is set.
    • Windows: %LOCALAPPDATA%\<subdir>\<subdir>\Cache (per platformdirs).

    If envkey names a nonempty environment variable, that variable's value is used as the root instead, with subdir appended when supplied. envkey is opt-in; there is no implicit DATACACHE_* override for all APIs. To use a variable's value as the root itself without appending subdir, see get_cache_root.

    Parameters:

    Name Type Description Default
    subdir str or None

    Application name; defaults to "datacache" when omitted or empty.

    		 None
    envkey str or None

    Optional environment variable name overriding the platform cache root.

    		 None

    Returns:

    Type Description
    str

    Selected directory path (not created on disk).

    Raises:

    install_zip_member ¶

    install_zip_member(destination, url, member, *, expected_sha256=None, expected_size=None, compressed_sha256=None, max_compressed_bytes=512 * 2 ** 20, max_bytes=4 * 2 ** 30, max_metadata_bytes=8 * 2 ** 20, timeout=60, force=False, offline=None)

    Fetch one explicitly named HTTP ZIP member into a shared, atomic bundle.

    Only stored and deflated, unencrypted regular members are supported (ZIP64 is supported). The server must support exact HTTP byte ranges, identity encoding, and a strong ETag or Last-Modified (Last-Modified is weaker than a strong ETag); there is no whole-archive fallback. Duplicate names, malformed ranges, changed objects, CRC mismatches, unsupported members, and size-limit violations fail before publication and preserve previous generations. Cache hits verify all retained bytes offline.
